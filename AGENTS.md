# Busnes.app organization guidance

## Purpose

Own the public organization profile and shared contribution/security policies.

## Ownership

- `profile/README.md` owns the public product directory and contributor entry points.
- `CONTRIBUTING.md` owns the suite-wide major-functionality test and warning-handling requirements; product guides own their commands and local constraints.
- `SECURITY.md` owns shared private vulnerability reporting.

## Local Contracts

- Keep product capabilities and setup links grounded in their maintained repositories.
- Shared policies apply to the Ky projects; they do not replace product security boundaries or verification commands.

## Work Guidance

- Record durable shared policy changes here and in their owning public policy document.

## Verification

- Check Markdown link destinations and run `git diff --check` for documentation changes.

## Child DOX Index

None. This root owns the profile and shared policies.
