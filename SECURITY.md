# Security Policy

This policy covers every Busnes-app repository that does not have its own `SECURITY.md`. A
repository's own policy takes precedence.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub, not in a public issue:

1. Open the repository's **Security** tab and choose **Report a vulnerability**.
2. Describe the problem, the affected versions, and how to reproduce it.
3. Do not disclose it publicly until a fix is released.

If you cannot use GitHub, email hello@busnes.app with "Security" in the subject.

## What happens next

- We acknowledge your report within 2 business days, then send a severity assessment and a
  timeline.
- Target time to public disclosure: 30 days for critical issues (unauthenticated data access,
  authentication bypass, remote code execution), 60 days for high, 90 days for moderate.
- The fix is released before the advisory is published.
- We credit you in the release notes unless you would rather stay anonymous.

## Audit status

No Ky product has had an independent security audit yet. Each product's README and
`SECURITY.md` state what it protects and where its trust boundaries are.
